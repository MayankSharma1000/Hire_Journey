# HireJourney

Your Personal Job Application CRM

Track applications, manage interviews, schedule follow-ups, and organize your job search journey.

## Features

- User Authentication
- Kanban Board
- Follow-up Reminders
- Google Calendar Integration
- Salary Tracking
- Notes
- CSV Export
- Dark Mode
- Responsive Design

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Calendar API
